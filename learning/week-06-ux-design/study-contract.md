# Learning Contract — UX AI: mengurangi kesalahan keputusan manusia, bukan sekadar membuat dashboard rapi

**Status:** intended outcomes, belum lulus/terverifikasi.

## LO-1

**Dapat dilakukan:** Memetakan task dan error flow dari inquiry hingga keputusan agent.

**Evidence:** berikan satu artefak asli (kode/diagram/test/design record) dan jelaskan reasoning + failure case, tautkan commit setelah praktik.

**Evaluation:** jelaskan input, outcome expected, outcome aktual, serta keterbatasan.

## Completion criteria

- [ ] Dapat mengerjakan *worked example* tanpa membaca solusi.
- [ ] Dapat menyelesaikan satu variasi baru dari kasus capstone.
- [ ] Dapat mendemonstrasikan negative test saat implementasi tersedia.
- [ ] Dapat menyebutkan security/privacy/reliability risk utama.
- [ ] Telah mencatat sumber, hasil nyata, dan batasan eksperimen.

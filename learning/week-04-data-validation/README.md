# Week 04 — Data Validation

**Status:** Not started · [Roadmap](../../docs/learning-roadmap.md) · [Tracker](../../docs/progress-tracker.md)

## Learning objective

Define measurable data-quality rules and reject or repair invalid records.

## Topics

Completeness; validity; uniqueness; consistency; Pydantic; schema evolution; leakage and privacy.

## Hands-on assignment

Add validation rules and negative tests for missing fields, malformed timestamps and duplicate IDs.

## Expected evidence

Validation code/tests; data-quality report.

## Review question

What is the difference between a valid record and an accurate record?

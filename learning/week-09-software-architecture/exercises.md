# Latihan Mandiri — Software Architecture for AI-Enabled Applications

## Tugas

1. A: Tambah sequence diagram untuk request tanpa izin dan jelaskan respons tepat.

2. B: Buat ADR modular monolith vs microservices dengan threshold pemisahan.

3. C: Jelaskan strategi migrasi model tanpa mengubah consumer API.

## Review checklist
- [ ] Keputusan dapat dijelaskan, termasuk alternatif dan konsekuensi.
- [ ] Hasil dapat direproduksi oleh rekan engineer tanpa akses privat.
- [ ] Happy path dan failure/negative path benar-benar diverifikasi.
- [ ] Data yang digunakan sintetis, tidak ada API key atau PII nyata.
- [ ] Keterbatasan dan ide perbaikan didokumentasikan.

Simpan refleksi dan test evidence. **Membaca latihan tidak berarti menyelesaikannya.**

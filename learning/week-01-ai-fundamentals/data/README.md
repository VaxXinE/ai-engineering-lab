# Dataset Sintetis Modul 01

Format CSV UTF-8: dua kolom **text,label**. Label: sales, support, general.

- train.csv: 54 contoh sintetis berbahasa Indonesia (18 per label).
- test.csv: 18 contoh sintetis berbeda (6 per label).
- Semua data **dibuat untuk latihan**, bukan dari CRM, chat, atau customer asli.
- Split bersifat tetap; belum memakai random split, cross-validation atau semantic deduplication.
- Pola kalimat sengaja sederhana dan tidak mewakili real-world traffic.
- Tidak mengandung nama, email, nomor telepon, account ID atau credential pelanggan.

Jangan mengganti data dengan chat customer nyata. Untuk Week 03, gunakan dataset sintetis yang lebih representatif dan prosedur split/evaluasi yang repeatable.

## Pola tiap modul

1. **theory.md**: pembahasan konsep, alasan teknis, dan risiko.
2. **lab-guide.md**: skenario implementasi bertahap dan acceptance criteria.
3. **exercises.md**: tugas yang perlu dikerjakan sendiri.
4. **assessment.md**: pertanyaan untuk menguji pemahaman serta bukti demo.
5. **README.md**: tujuan dan navigasi.

Jangan memberi status "selesai" ketika baru membaca materi. Gunakan [progress tracker](../docs/progress-tracker.md) dan [evidence matrix](../certification/evidence-matrix.md) untuk memverifikasi hasil.

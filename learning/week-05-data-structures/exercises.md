# Latihan Mandiri — Week 05

## Tugas inti

1. A: Ubah dedup agar 'last wins' dan jelaskan perubahan ordering.

2. B: Bandingkan O(n²) versus O(n) secara analitis dan ukur secara lokal.

3. C: Bagaimana desain streaming jika file tidak muat memori?

## Mini code-review / design-review

Tinjau hasil tugas dengan sudut pandang rekan engineer. Tuliskan: **(a)** satu asumsi yang belum dibuktikan, **(b)** satu edge case berisiko, **(c)** satu trade-off keputusan, **(d)** langkah pengujian agar klaimnya bisa diverifikasi.

## Rubrik mandiri

| Dimensi | Bukti memadai |
| --- | --- |
| Pemahaman | Mampu menjelaskan *mengapa* pilihan diterapkan dan kapan alternatifnya lebih baik |
| Implementasi | Artefak dapat direproduksi, bukan sekadar screenshot |
| Testing | Ada negative cases dan hasil aktual, bukan klaim |
| Security | Data sintetis, izin akses, input dan secrets ditangani sesuai konteks |
| Dokumentasi | PR/commit, keputusan, dan keterbatasan dapat ditelusuri |

**Batasan:** jawaban dan benchmark tidak disediakan sebagai hasil palsu. Isi saat kamu benar-benar menjalankan praktik.

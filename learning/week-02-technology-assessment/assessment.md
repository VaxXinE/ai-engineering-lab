# Simulasi Asesmen — Week 02

**Ini latihan pribadi, bukan soal, asesmen, atau panduan resmi BNSP.**

## Tanya jawab teknis

1. Mengapa memilih berdasarkan bintang GitHub saja berisiko?

2. Bagaimana license compatibility memengaruhi produk komersial?

3. Apa beda model lokal dan API eksternal dari sisi privacy dan latency?

4. Kapan aturan keyword lebih baik daripada LLM?

5. Mengapa decision matrix harus menyimpan asumsi dan bukti?

6. Bagaimana menangani dependency tanpa maintainer aktif?

7. Apa indikator perubahan teknologi sudah perlu dipertimbangkan?

8. Apa risiko ketika model AI diganti tanpa regression evaluation?

## Demo praktis yang perlu disiapkan

- [ ] Tunjukkan bukti: Tiga strategi AI dibandingkan dengan bobot eksplisit dan rasional penilaian.
- [ ] Tunjukkan bukti: ADR memuat alternatif yang ditolak beserta konsekuensinya.
- [ ] Tunjukkan bukti: Dependency dan lisensi utama dicatat tanpa hardcoded API key.
- [ ] Tunjukkan bukti: Ada rencana validasi berbasis pengukuran, bukan hanya opini.

## Penilaian diri

- **Belum bisa:** belum dapat menjelaskan atau mendemonstrasikan.
- **Perlu latihan:** bisa dengan bantuan tetapi belum konsisten.
- **Mandiri:** bisa menjelaskan dan mendemonstrasikan sendiri, beserta error path.
- **Siap dievaluasi:** bukti direproduksi dan risiko tersisa dijelaskan.

Jangan menganggap skor ini menentukan status **Kompeten** BNSP. Keputusan resmi memerlukan prosedur dan asesor LSP.

# Synthetic Data Policy

Only **generated or demonstrably synthetic** data should enter this directory.

- Do not use real client names, phone numbers, emails, account IDs, chats or transaction data.
- Label every sample as synthetic and state how it was generated.
- Document schema, field types, seed, licensing and intended use.
- Keep private/raw datasets outside Git and inside ignored folders.
- Avoid training/evaluating on overlapping records that cause leakage.

Initial dataset: **not generated**. It will be created during Week 03.

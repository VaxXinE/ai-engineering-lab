## Evidence plan

- Tools/framework comparison and ADRs.
- UX flows, responsive UI demo and accessibility checklist.
- ERD, database migration, API contracts and architecture diagrams.
- Load and reliability analysis.
- Demonstrable inference integration, installation and maintenance routines.

Every artifact should have reproducible steps and actual validation evidence. See [matrix](../evidence-matrix.md).
